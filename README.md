# BauKo NRW - Website (Next.js starter)

This repository contains a ready-to-deploy Next.js website for BauKo NRW.
It is configured as a minimal static Next.js project with public assets and pages.

How to run locally:
1. npm install
2. npm run dev
3. Open http://localhost:3000

Deploy to Vercel:
1. Push to GitHub
2. Import project in Vercel -> Deploy
